# Proyecto

## Clonar el Repositorio

Para clonar el repositorio y descargar el código, sigue estos pasos:

1. Abre una terminal o línea de comandos.
2. Ejecuta el siguiente comando:

```bash
git clone https://github.com/lsp12/Nestjs-Test-02.git
```

3. Navega al directorio del proyecto clonado:

```bash
cd Nestjs-Test-02
```

4. Cambia a la rama específica:

```bash
git checkout test/jonathan-vera
```

Ahora tendrás el código descargado en tu máquina local.
